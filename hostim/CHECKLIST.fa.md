# چک‌لیست وضعیت — نسخهٔ Hostim

تاریخ: ۲۰۲۶-۱۰-۱۰ · شاخه: `arena/19c5b0b6-majidautomationsystem-colab-br`

این فایل یک گزارش صادقانه است، نه تبلیغ. هر ردیف یکی از این چهار علامت را دارد:

| علامت | معنا |
|---|---|
| ✅ | **انجام و تأیید شده** — یا در استقرار واقعی دیده شده، یا با تست خودکار سنجیده شده |
| 🧪 | **نوشته شده و با تست خودکار سنجیده شده، اما هرگز داخل کانتینر واقعی اجرا نشده** |
| ⚠️ | **نیمه‌تمام / مشروط** — کار می‌کند اما یک پیش‌نیاز دستی یا یک محدودیت دارد |
| ❌ | **انجام نشده** — عمداً، یا چون هنوز نرسیده‌ایم به آن |

> قانون این پروژه: هر چیزی که در محیط واقعی ندیده‌ایم، «تأییدنشده» می‌ماند.
> تست‌های خودکار همه با **بدل** (fake) اجرا می‌شوند: بدون X server، بدون مرورگر،
> بدون شبکه، بدون تلگرام. پس «سبز بودن تست» یعنی منطق درست است، نه یعنی روی
> Hostim هم حتماً کار می‌کند.

## ۷. حالا چکار کنم؟ (به ترتیب)

1. **Rebuild در Hostim** — کنسول → اپ → Deploy/Rebuild از همان شاخهٔ
   `arena/19c5b0b6-majidautomationsystem-colab-br`. کانتینر فعلی روی کامیت قدیمی است.
2. **پنل را باز کن** → `https://af9833d9.eu-center.hostim.dev/automation/panel.html`
   (یا از داخل noVNC). تب اول باید «چت» باشد و تب دوم «کتابخانه».
3. **نشانگر را ببین** → ایجنت → «نشانگر» → ذخیره و اعمال → «حرکت نشانگر برای دیدن».
   اگر زرد و بزرگ ندیدی، همان‌جا بگو تا مسیر Xcursor را امتحان کنیم (این تنها
   خواسته‌ای است که ممکن است در Xvfb جواب ندهد).
4. **کلید ایجنت** → ایجنت → «کلید ایجنت» → 👁 نمایش → 📋 کپی. بعد امتحان:
   ```bash
   curl -H "x-agent-key: <کلید>" https://af9833d9.eu-center.hostim.dev/automation/api/agent
   ```
   و با «⏸ قطع دسترسی» همان دستور باید **۴۰۳** بدهد.
5. **تلگرام** → ایجنت → «تلگرام»: حالت را «هر دو» بگذار، توکن ربات را بگذار،
   گیرنده را «پیدا کردن چت‌ها» کشف کن، و در بخش ۶ یک پیام آزمایشی **با گیرنده** بفرست.
6. **چت** → یک پرسش بنویس. اگر مرورگر ایجنت بالا نیامده باشد، پیام خطا صریح می‌گوید
   چه چیزی کم است (نه یک ۵۰۰ خالی).
7. **کتابخانه** → «اتصال به ایجنت lmarena» را «باز کردن در مراحل» بزن، بعد ▶ اجرا.
8. **صفحه‌ها** → «شناسایی صفحه» → اول اسکرین‌شات می‌آید → روی یک عنصر «کلیک واقعی».

هر کدام که کار نکرد، **متن خطا و لاگ** را بفرست تا همان نقطه را درست کنم.

### الان چکار کنم؟ (کوتاه)
1. Rebuild از همان شاخهٔ `arena/19c5b0b6-majidautomationsystem-colab-br`.
2. یک‌بار Ctrl+Shift+R روی پنل.
3. تب «دیتابیس» → گرفتن پشتیبان → دانلود؛ بعد «فرستادن پشتیبان» با آی‌دی کانال خودت.
4. تلگرام → «🩺 تست کامل مرحله‌به‌مرحله» → عکس نتیجه را برایم بفرست اگر قدمی قرمز بود.
5. راست‌کلیک روی دسکتاپ noVNC → منوی فارسی را ببین؛ اگر رنگ/چیدمان نپسندیدی بگو.

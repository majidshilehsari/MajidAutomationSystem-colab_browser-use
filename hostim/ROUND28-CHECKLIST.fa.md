## گزارش اجرا
- **گام ۸ (مورد ۸ — سه تب پشتیبان‌گیری: دستی/تلگرام/سوپابیس):** زیرزیرتب‌ها با تصمیم خودکارِ جداگانه؛ آپلود فایل شخصی (/agent/backup-upload با اعتبارسنجی)؛ رفت‌وبرگشت کامل تلگرام: ذخیرهٔ اطلاعات پیام هنگام ارسال (backup.telegramSent) و دانلود همان فایل با getFile (+HTTPS GET) از مسیر /agent/backup-fetch؛ Notifier اکنون details هر فایل ارسال‌شده را برمی‌گرداند. تست: پایتون ۶۳۶ OK · UI ۹۲ · core ۲۳.
- **گام ۷ (مورد ۴ — مودال سازگاری بازیابی):** مسیر /agent/backup-inspect با حکم واقعی per-item (SQLite/integrity_check برای دیتابیس، اعتبارسنج+ترجمهٔ خودکار برای عملیات‌ها)؛ مودال جدول 🟢/🔴 با پیش‌فرض «همهٔ سازگارها» و انتخاب دانه‌دانه؛ restore انتخابی (پارامتر items) با رد ۴۰۹ برای قلم قرمز و ۴۰۰ برای قلم ناشناخته؛ استخراج امن مشترک (_extract_staged) بین inspect و restore. تست: ۵ تست پایتون + بازنویسی تست UI.
- **گام ۶ (مورد ۲ — ثبت عملیات با مودال):** «عملیات تازه» و ✎ ویرایش → مودال «💾 ذخیرهٔ عملیات/ویرایش»؛ حذف ویرایشگر درون‌خطی؛ saveOperation با onClose. تست: ۱ تست UI تازه (کاممیت f68053a).
- **گام ۵ (مورد ۱ — سیستم سلول، هر سه برش):** موتور (params/S/set_output/pause_all + outputs/watch در نتایج)، schema (settings/outputs/lastReport)، UI (رنگ سلول، ▶/⏸/⏹، مودال ۵ تب، merge گزارش/خروجی در هر تب)، و راهنمای ایجنت (ai_guide.md + agent.md) پیاده شد. همهٔ تست‌ها سبز.
- **گام ۴ (طراحی مورد ۱ — سیستم سلول، بدون کد):** نقشهٔ اجرا در سه برش:
  - **برش ۱ (مدل داده + موتور):** هر سلول = همان مرحلهٔ پایتون با افزوده‌ها: `label` (تیتر، از قبل هست)، `note` (توضیح مفصل تب ۳، از قبل هست)، `settings` (فهرست پارامترهای کاربرپسند: کلید، برچسب فارسی، نوع number/text/select/bool، مقدار، unit='s' برای ثانیه) و `outputs` (خروجی‌های مشخص تب ۴). در فضای exec سلول: `params` (دیکشنری تنظیمات)، `S('wait', 3)` (پیش‌فرض بر حسب **ثانیه**)، `set_output(key, value)` (ذخیرهٔ خروجی تعاملی، مثلاً سن/پیکسل/پاسخ AI)، `pause_all(reason)` (سلول گوش‌به‌زنگ: به‌محض دیدن عبارت خاص همهٔ عملیات را متوقف می‌کند تا حل شود). schema این فیلدها را اعتبارسنجی می‌کند.
  - **برش ۲ (UI):** کارت سلول در تب مراحل: تیتر + شماره + رنگ (سبز=انجام شد، زرد=در حال اجرا — سلول پایشگر می‌تواند زرد بماند در حالی که سلول بعدی اجرا می‌شود، قرمز=خطا) + پلی/پاز/استاپ جداگانه. کلیک روی سلول → مودال با نام عملیات و ۵ تب: (۱) تنظیمات (۲) گزارش متنی فارسی (انجام شد/خطا چه بود) (۳) توضیح فارسی مفصل (۴) خروجی مشخص (تعاملی + دکمهٔ کپی؛ پاسخ AI هم می‌تواند اینجا بنشیند) (۵) اسکریپت پایتون، زیبا و مرتب. کد از اول دیده نمی‌شود — فقط تیتر.
  - **برش ۳ (اجرای تک‌سلول + بستر ایجنت):** API اجرای یک سلول (با تزریق params و ضبط outputs و گزارش)، جفت‌شدن گزارش/رنگ با نتایج موتور، مکانیزم pause_all برای سلول گوش‌به‌زنگ، و به‌روزرسانی راهنمای ایجنت (agent.md) تا ایجنت همکار بتواند این سلول‌ها را خوب بنویسد (تنظیمات پذیر، خروجی مشخص، توضیح فارسی).
- **گام ۳ (باند C: مورد ۶ + پایانی مورد ۵):** روش JSON از سطح کاربر برچیده شد (دکمه‌های کلیپ‌بورد JSON + پنجرهٔ چسباندن + شاخهٔ مردهٔ ویرایشگر + ترجمهٔ خودکار جریان قدیمی در بوت)؛ پرامپت چت و همهٔ رشته‌های فارسی پایتون (api/agent/engine/schema/telegram/backup) به واژه‌شناسی «عملیات/مرحله» منتقل شدند. همهٔ تست‌ها سبز.
- **گام ۲ (باند B: مورد ۳):** زیرتب «پرامپت» و کل گردش کار کپی/واردکردن JSON حذف شد (فرانت + سه مسیر بک‌اند + API_INDEX + ۷ تست پایتون + ۲ تست JS + مستندات).
- **گام ۱ (باند A: موارد ۵+۷):** واژه‌شناسی «عملیات/مرحله/سلول» جای «جریان» نشست و بخش «تنظیمات جریان» کامل حذف شد (دکمه + مودال + برچسب‌ها + تست‌ها به‌روز). همهٔ تست‌ها سبز: پایتون ۶۳۶ OK · JS ۱۱۳ (۹۰+۲۳).
